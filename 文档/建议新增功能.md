# 建议新增功能

## 一、建议目标
结合当前系统已有能力（GTFS 静态数据、实时数据、准点率统计、收藏、后台管理），新增功能建议以三点为主：
1. 提升用户日常使用价值（查得到、看得懂、能提醒）。
2. 提升运营管理价值（可监控、可追踪、可复盘）。
3. 控制实施风险（优先复用现有 API 与数据库结构，分阶段上线）。

---

## 二、优先级建议（P0-P2）

## P0（优先上线）

### 1. 到站时间 ETA 预测与误差展示
- 功能说明：在站点详情页和路线详情页展示“预计到站时间”，并显示与计划时刻的偏差（提前/延误）。
- 用户价值：用户最关心“车多久到”，这是使用频率最高的核心功能。
- 实施要点：
  - 后端新增 ETA 计算服务（融合 `tripupdates`、车辆位置、历史速度）。
  - 前端在 `Stops/StopDetail/RouteDetail` 增加 ETA 卡片与颜色状态标识。
  - 增加误差评估指标（MAE、P50/P90）用于持续优化模型。

### 2. 延误预警与订阅通知
- 功能说明：用户可订阅线路/站点，当延误超过阈值（如 5 分钟）时触发通知。
- 用户价值：从“被动查询”升级为“主动提醒”，提升留存和实用性。
- 实施要点：
  - 复用现有收藏能力，新增“订阅规则”配置（阈值、时段、工作日）。
  - 通道先做站内消息/页面红点，再扩展邮件或企业微信/Telegram Bot。
  - 后端增加定时任务和事件去重，避免重复提醒。

### 3. 实时告警中心（管理端）
- 功能说明：后台新增告警看板，展示异常线路、告警数量、恢复时长和当前状态。
- 用户价值：便于运营人员快速发现异常、定位问题、追踪处理结果。
- 实施要点：
  - 告警类型建议：大面积延误、接口拉取失败、区域数据中断、数据库写入异常。
  - 支持按地区（sf/nyc/sydney）筛选，按严重程度排序。
  - 记录告警生命周期：触发时间、确认时间、恢复时间、责任人。

## P1（第二阶段）

### 4. 多维度准点率分析报表
- 功能说明：新增按“时段/星期/天气（可选）/线路类型/地区”的对比分析和趋势图。
- 用户价值：把“当前状态”升级为“规律洞察”，支持运营优化和汇报。
- 实施要点：
  - 在现有准点率聚合基础上增加维度字段和物化统计表。
  - 前端支持筛选器联动、图表导出（PNG/CSV）。
  - 提供周报/月报模板（自动生成摘要）。

### 5. 地图交互增强（热力图 + 回放）
- 功能说明：地图页增加延误热力图、车辆轨迹回放、拥堵区高亮。
- 用户价值：直观理解“哪里堵、何时堵、持续多久”。
- 实施要点：
  - 轨迹数据按时间窗口聚合，降低前端渲染压力。
  - 增加回放速度控制、时间轴拖拽。
  - 采用分层渲染（点位层/轨迹层/热力层）保障性能。

### 6. 数据质量监控（Data Quality）
- 功能说明：自动检测数据缺失、字段异常、延迟升高，并生成质量评分。
- 用户价值：减少“结果看起来正常但数据已失真”的风险。
- 实施要点：
  - 定义质量规则（完整性、及时性、一致性、唯一性）。
  - 质量评分纳入后台首页，并支持异常明细下钻。
  - 建议接入每日巡检任务，产出巡检日志。

## P2（中长期）

### 7. 路线优化与调度建议（决策辅助）
- 功能说明：基于历史准点率和客流 proxy 数据给出“高风险时段/路段”和调度建议。
- 用户价值：为管理方提供可执行的策略建议，而不只是展示数据。
- 实施要点：
  - 首先输出规则型建议（非机器学习），再逐步演进。
  - 结果以“建议卡片 + 证据数据”形式展示，提升可解释性。

### 8. 开放数据 API 与第三方集成
- 功能说明：提供稳定的对外查询 API（限流、鉴权、文档、版本管理）。
- 用户价值：支持校内/团队其他系统复用，扩大系统影响力。
- 实施要点：
  - 明确 API version（如 `/api/v1/...`）。
  - 引入访问令牌、配额和审计日志。
  - 提供最小可用 SDK（JS/Python）示例。

---

## 三、建议实施顺序（8-12 周）
1. 第 1-3 周：ETA 预测（P0-1）+ 基础误差评估。
2. 第 4-6 周：延误订阅通知（P0-2）+ 告警中心（P0-3）。
3. 第 7-9 周：多维报表（P1-4）+ 地图增强（P1-5）。
4. 第 10-12 周：数据质量监控（P1-6），并评估 P2 方案可行性。

## 四、验收指标建议
- 用户侧：查询到站功能使用率、订阅开启率、通知点击率。
- 业务侧：严重延误发现时延、告警平均恢复时长（MTTR）。
- 技术侧：实时接口可用性、数据延迟、ETA 误差（MAE/P90）。
